快速开始

GeminiProxy 是一款专为国内用户优化的一键式 Gemini API 反向代理脚本。通过简单的 Shell 指令，即可在您的 VPS 上搭建稳定的 API 通道。

功能特性

  • 单一命令完成部署，支持 Ubuntu/Debian/CentOS/Arch
  • 自动优化网络连接，解决 Gemini 访问受阻问题
  • 集成 Nginx 自动配置与 SSL 证书申请

1. 服务器准备

部署前请确保您拥有一台具备公网 IP 的服务器，并建议使用 root 用户登录。推荐使用马来西亚、韩国、日本等亚洲区域的 VPS 以获得更佳延迟。

2. 执行安装命令

注意： 若选择使用 Nginx，请确保您的域名已解析至当前服务器 IP。NAT 服务器用户请务必选择脚本中的第 4 种 SSL 获取方式。

在 SSH 终端（推荐使用 Xshell 或 FinalShell）中复制并运行以下任一命令：

# 推荐方式：下载、执行并自动清理
wget https://raw.githubusercontent.com/Cnfte/geminiproxy/refs/heads/main/proxy.sh && sudo bash proxy.sh && rm proxy.sh

3. 客户端配置

安装成功后，您可以在 Chatbox 等 AI 客户端中直接填入您的代理域名进行通信。

关于 API Key： 本脚本不提供 Key，您需要前往 Google AI Studio 自行获取。

配置完成后，即可享受无缝的 Gemini 交互体验！
