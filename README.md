# geminiproxy ✨
**一键轻松搞定Gemini反向代理，让你在国内也能丝滑畅聊！**

---

### 这个脚本能帮我做什么？
*   **超简单安装：** 只需一个命令，就能在你的Linux服务器上搭建Gemini反向代理。
*   **系统全支持：** 无论是Ubuntu、Debian、CentOS还是ArchLinux，统统搞定！
*   **畅通无阻：** 解决你访问Gemini时遇到的各种网络障碍。

### 友情提醒 💡
*   如果你打算用Nginx来做反代，记得要**提前准备好SSL证书**哦！
*   安装完成后，别忘了把你的**域名解析到服务器的公网IP地址**。
*   **敲黑板！划重点！** 这个脚本只是帮你“曲线救国”访问Gemini，它**不会**把Gemini的API格式转成OpenAI的格式哦！别搞混啦！
*   最后一步，把你的域名填进Chatbox这类AI聊天软件，就能愉快地和Gemini玩耍了！

---

## 🛠️ 手把手教你安装（超简单，看一遍就会！）

### 1. 准备你的“小金库”服务器 💻
无论是带独立IP的服务器，还是像`sadidc.cn`那种NAT服务器（比如他们家的澳大利亚NAT主机），都没问题！只要能上网就行~

### 2. 登陆你的服务器 🔑
首先，找到你的服务器的登录信息（通常是`root`用户和密码）。
**小提示：** 确认一下你的服务器是不是已经“醒”过来啦？如果还在“睡觉”，赶紧手动开机唤醒它！
然后，用你喜欢的SSH工具（比如Xshell、FinalShell）连接到服务器。

![查找登录信息和确保服务器开机](img/1.jpg)
*图1：找到你的登录凭证，确保服务器是开机状态*

![使用SSH工具连接到服务器](img/2.jpg)
*图2：通过Xshell或FinalShell连接你的服务器*

### 3. 开始安装咯！🚀
准备好了吗？接下来就是激动人心的安装时刻！

*   **复制我们的“魔法咒语”（部署代码）：**
    ![复制部署代码](img/3.jpg)
    *图3：复制一长串神秘代码*

*   **把它粘贴到你的服务器终端里，然后按下回车键！**
    ![粘贴代码并回车执行](img/4.jpg)
    *图4：粘贴代码到终端，然后勇敢地按下回车！*

*   你会看到一个酷炫的管理面板。别犹豫，直接输入数字 **1**，选择 **安装反代**！
*   接着，脚本会问你一些问题，比如你的**域名**、**映射端口**，以及**SSL证书的获取方式**（**NAT机器的小伙伴注意啦，这里只能选第4种方式获取SSL证书哦！**）。
    ![输入安装所需信息](img/5.jpg)
    *图5：按照提示输入你的域名、端口和SSL选择*

*   (友情提示：这里我已经安装过了，就不重复演示啦，你懂的~)
*   搞定这些，最后一步就是把你的域名解析到服务器的公网IP（如果你是NAT服务器，记得还要做好端口映射再解析哦！）

### 4. 终于能用啦！🎉
安装完毕，现在就来看看怎么使用你的Gemini代理吧！

*   打开你常用的AI聊天软件，比如Chatbox的App版或者Web版。
    ![打开Chatbox应用](img/6.jpg)
    *图6：打开你的Chatbox应用或网页版*

*   找到设置按钮，点进去！
    ![点击设置按钮](img/7.jpg)
    *图7：进入Chatbox的设置界面*

*   把你的代理域名填进去，还有Gemini的API Key（**这个Key需要你自己“翻山越岭”去ai.dev官网获取哦！**）。
*   一切搞定！现在，你可以和小G畅聊人生、探索宇宙，无拘无束啦！

## 🚀 安装命令（三选一就好！）

选择一个你最喜欢的方式来执行下面的命令吧：

```shell
# 方法一：下载脚本后手动运行（推荐给想看清楚每一步的你！）
wget https://raw.githubusercontent.com/Cnfte/geminiproxy/refs/heads/main/proxy.sh
sudo bash proxy.sh
# 方法二：下载并立即运行脚本（一气呵成，简单快捷！）
wget https://raw.githubusercontent.com/Cnfte/geminiproxy/refs/heads/main/proxy.sh && sudo bash proxy.sh
# 方法三：下载、运行并删除脚本（用完即走，不留痕迹！）
wget https://raw.githubusercontent.com/Cnfte/geminiproxy/refs/heads/main/proxy.sh && sudo bash proxy.sh && rm proxy.sh
```
